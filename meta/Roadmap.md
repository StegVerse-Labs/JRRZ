# JRRZ Project Roadmap

## Purpose of this document

This document tracks durable delivery stages for JRRZ.

## Current stages

1. **Public foundation — implemented:** minimal homepage, interactive joint map, recovery trajectory, Hip Zone, Knee Zone, roadmap, recovery model, systems comparison, shared footer, and deployment workflow.
2. **Validation and activation — active:** observe the repository workflow, confirm GitHub Pages deployment, inspect the public runtime, and correct any failures.
3. **Clinical reference foundation — planned:** install verified source registry and reviewer records.
4. **Zone expansion — planned:** move selected joints from In Surgery to In Recovery and then Live only with owners, evidence, and launch dates.
5. **Braun review — pending public activation:** present the test site and record feedback without implying endorsement.

## Development notice

Dates and owners will be added only when they are durably claimed.
