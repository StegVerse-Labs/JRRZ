# Recovery Milestone Map

## Purpose of this document

This document defines how JRRZ will present recovery milestones without treating a population pattern as an individual promise.

## Milestone categories

- safety and symptom monitoring;
- assisted and independent mobility;
- transfers and daily activities;
- strength, balance, and endurance;
- return to sustainable activity;
- long-term joint protection.

## Interpretation rule

Milestones are descriptive educational checkpoints. Individual timing depends on the procedure, health status, complications, rehabilitation plan, and treating team's instructions.
