# Clinical References

## Purpose of this document

This document is the planned registry for clinical guidelines, peer-reviewed studies, patient-reported outcome instruments, and trusted patient-education sources used by JRRZ.

## Reference fields

Each entry should include title, author or issuing body, publication date, retrieval date, URL or DOI, affected JRRZ content, and review status.
